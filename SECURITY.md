# Security policy

This is a portfolio exercise, not a medical device: it must never be used on people. Its security is still taken seriously, and it follows the [cybersecurity management plan](docs/security/management-plan.md) a manufacturer would.

## Reporting a vulnerability

Report it privately, from this repository's **Security** tab: **Report a vulnerability**. Please don't open a public issue.

You'll hear back within five working days. The vulnerability is then assessed with the method in the [risk assessment](docs/security/risk-assessment.md), and you're told its score and when a fix is planned. An advisory is published once the fix is available, or after 90 days if it isn't, unless you agree to wait, and you're credited if you wish.

## Supported versions

Only the latest release gets fixes.
